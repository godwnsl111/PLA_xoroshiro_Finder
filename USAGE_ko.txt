============================================
 PLA Reverse Finder  (합법 세트 역산 도구)
============================================

Pokemon Legends: Arceus 개체를 PKHeX에서 편집할 때,
[조우 타입 / 종류 / IV / 성격 / (야생) 키·몸무게]를 넣으면
그 개체를 만들어내는 "합법 Xoroshiro" 세트
(EC / PID / IVs / 특성 / 성격 / 성별 / 키 / 몸무게 / seed)를
여러 개 역산해서 표로 보여줍니다.


■ 실행
--------------------------------------------
- PLA_Reverse_Finder.exe 더블클릭. 파이썬 설치 필요 없음(Windows 64bit).
  (Defender 경고 시 "추가 정보 → 실행". PyInstaller 미서명 exe라 그런 것.)
- 파이썬으로:  python pla_reverse_finder.py
  (로직 검증만:  python pla_reverse_finder.py --selftest)


■ 게임 생성 순서 (이해용)
--------------------------------------------
  EC → PID(롤) → IV → 특성 → [성별] → 성격 → [키 → 몸무게]

* 성별: 무성/고정 성별 종류는 성별을 "안 굴려서" 그 뒤의 성격·키·몸무게가
        한 칸 밀립니다. → 아래 "성별 롤" 설정으로 처리.
* 키/몸무게(사이즈 스칼라 0~255): 성격 다음에 seed로 굴려짐.
    - 야생·전설·우두머리 모두 동일하게 rand(0x81)+rand(0x80)로 생성 → 전부 검색 가능.
    - (예전 "전설=127 / 알파=255 고정"은 틀린 정보였음. pla-reverse 실제 코드로 확인·수정.)


■ 사용법
--------------------------------------------
1. [조우 타입] 선택
   - 야생 오버월드 : 보장IV 0, 키/몸무게 검색 가능
   - 전설/정적     : 보장IV 3, 키/몸무게 검색 가능
   - 우두머리       : 보장IV 3, 키/몸무게 검색 가능
   (선택하면 보장IV·성별롤·사이즈칸이 자동으로 맞춰집니다.
    보장 31 IV는 조우 타입으로 자동 결정되어 수동 편집은 막혀 있습니다.)
2. [종류] 선택 → 그 종의 성별 비율을 알아서 판정해서 "성별 롤"과
   "성별 비율"을 자동 설정합니다. (예: 크레세리아=암컷만, 메타몽=무성,
   로토무=무성, 이상해씨류=수컷 87.5%). 결과 표의 성별도 암/수/무성으로 표시.
   ※ 한국어 이름으로도 입력/선택 가능 (예: "크레세리아", "메타몽").
     영어는 대소문자 무시 (arceus = Arceus). 드롭다운은 한국어명이 먼저 나옵니다.
   ※ PLA 등장 종은 모두 내장. 목록에 없는 종은 아래 성별 롤/비율을 수동 설정.
3. [IV] 6칸 입력. 빈칸/x = 아무값.  위 "6V"/"5V(공격무시)" 버튼으로 빠르게.
4. [성격] 선택 (무관 가능)
5. [특성 슬롯] PKHeX 현재 개체와 같은 걸로 (모르면 "무관")
6. [성별 롤]
   - 자동(양쪽 다 시도) : 성별 롤 있음/없음 결과를 둘 다 뽑아줌 (표 "성별롤" 열 Y/N)
   - 있음 : 성별 있는 보통 종류
   - 없음 : 무성/고정 성별 (전설 다수)
   ★ PKHeX에서 'PID 유형: Xoroshiro'가 안 뜨면 성별 롤을 반대로 바꿔 다시 찾으세요.
6-1. [성별 비율] 성별 롤이 '있음/자동'일 때 결과의 성별을 암/수로 표시하는 기준.
     (암1:수1, 암1:수3 … 프리셋. 무성 종류는 성별 롤을 '없음'으로 두면 "무성" 표시.)
7. [보장 31 IV] 조우 타입이 자동 설정 (전설/우두머리=3, 야생=0)
8. [롤 수] 기본 1
9. [키]/[몸무게] 0~255 · 빈칸=아무값 (모든 조우 타입에서 검색 가능)
10. [찾기] → 결과 표. 행 선택 후 "EC/PID/IV 복사" 버튼으로 PKHeX에 붙여넣기.


■ PKHeX에 넣는 법 (중요)
--------------------------------------------
한 행의 EC / PID / IVs / 성격을 "통째로" 넣어야 합니다.
하나라도 빠지면 "PID 유형: None"이 됩니다.

* EC(암호화 상수) 칸을 꼭 같이 바꾸세요! (실패 1순위 원인)
* 특성 슬롯이 표의 슬롯과 개체가 일치해야 합니다.
* 넣은 뒤 분석 → "PID 유형: Xoroshiro"로 바뀌면 정상.
* 여러 후보 중 안 되는 게 있으면 다음 행/성별롤 반대쪽을 시도.


■ 키 / 몸무게 / 배율
--------------------------------------------
* 표의 키/몸무게(스칼라 0~255)를 PKHeX height_scalar/weight_scalar에 입력.
  (도구는 스칼라만 출력 — 종별 기본 키·몸무게가 있어야 cm/kg 환산 가능하기 때문.)


■ 야생에서 결과가 안 나올 때 (중요)
--------------------------------------------
야생 오버월드는 "보장 31 IV = 0"이라 IV 6칸이 전부 무작위(각 1/32)입니다.
그래서 원하는 31 IV가 많을수록 확률이 급격히 낮아집니다:
  - 야생 6V + 성격 지정  ≈ 268억분의 1  (사실상 안 나옴)
  - 야생 3개31 + 성격     ≈ 82만분의 1   (느리지만 가능)
  - 야생 IV무관 + 성격    ≈ 25분의 1     (즉시)
반면 전설/우두머리는 31이 3개 보장이라 6V도 ≈ 82만분의 1로 나옵니다.

찾기를 누를 때 조건이 너무 드물면 예상 시도 횟수를 경고합니다.
해결: (1) 필요 없는 IV칸을 x(아무값)로 비우기,
      (2) 보장 IV가 있는 전설/우두머리 조우 타입 쓰기.


■ 색이 다른 포켓몬 / TID·SID (중요)
--------------------------------------------
* PLA는 개체 생성 시 seed에서 뽑은 '가짜 TID/SID'로 색이 다른 포켓몬를 판정합니다.
  이 도구의 기본 "색이 다른 포켓몬" 판정도 그것(=생성 시점 색이 다른 포켓몬)이라, 당신 게임에서
  실제로 반짝이는지와 다를 수 있습니다. 실제 색이 다른 포켓몬는 '진짜 TID/SID'로 정해지니까요.
* 색이 다른 포켓몬 PID는 게임(PLA) 실제 규칙대로 만듭니다:
    생성 색이 다른 포켓몬 seed의 원본 PID 하위16은 보존하고, 상위16을
    "하위16 ^ (내TID^내SID) ^ (사각0/별1)" 로 확정. (원본이 이미 내 기준
    색이 다른 포켓몬면 그대로 둠) — Lincoln-LM pla-pid-iv 검증 공식과 100% 일치.
* [TID]/[SID] 넣고 "색이 다른 포켓몬만" 체크 → 위 규칙으로 만든 합법 색이 다른 포켓몬 PID 출력.
    결과 표 "색이 다른 포켓몬" 열에 '사각★/별☆'로 표시.
* PID 유형 = None 정상: PKHeX는 색이 다른 포켓몬의 사라진 상위16(2^16)을 역탐색하지
    않아 seed 검출 실패 → PID 유형 None으로 뜹니다. 이건 불법이 아니라
    "정상이자 합법"입니다(PKHeX 개발자 Kaphotics 확인). 판단은 초록 "Legal!"로.
  ※ TID/SID 없이 색이 다른 포켓몬는 내 기준 확정을 못 하니 반드시 TID/SID를 넣으세요.
* TID/SID 입력 형식:
    - 기본: 게임/PKHeX 화면 그대로 TID 6자리(0~999999) + SID 4자리(0~4294).
      도구가 내부 16비트로 자동 변환합니다.
    - "16비트로 입력" 체크 시: 내부 16비트 값(0~65535)을 직접 입력. (10진수/0x 허용)
* 참고: EC/PID/IV/성격이 seed로 추적되면 개체 자체는 합법입니다.
  색이 다른 포켓몬 여부는 PID와 TID/SID로 정해지는 별개 요소예요.


■ 시드/PID가 자연스럽게 나옵니다
--------------------------------------------
* seed는 64비트 전 범위에서 무작위로 뽑습니다 → 결과 시드·PID가 초기값
  (0000...)에 몰리거나 PID가 한쪽으로 뭉치지 않고 골고루 흩어집니다.
* 고정 seed 값은 개체에 저장되지 않으므로 어떤 64비트 값이든 합법입니다.
* [찾기]를 다시 누르면 매번 다른 세트가 나옵니다(원하는 조합을 여러 번 리롤 가능).


■ 참고 (한글 성격 함정)
--------------------------------------------
  조심 = Modest   /   신중 = Careful   (자주 헷갈림)
